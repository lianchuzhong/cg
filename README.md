# 吃喝玩乐预约

无需注册、无需登录的吃喝玩乐在线预约站点。访客只要填写**昵称**或**手机号**任一项即可提交预约，并拿到预约码。

## 在线访问

> 站点已经部署到 GitHub Pages，直接点下面的链接就能用，**不用下载代码**。

| 页面 | 地址 |
| --- | --- |
| 预约首页 | https://lianchuzhong.github.io/cg/ |
| 仓库源码 | https://github.com/lianchuzhong/cg |

> 商家管理台**不在网站里**，是放在你电脑桌面上的离线文件：`E:\桌面1\商家管理台.html`。
> 双击即可打开，完全离线运行，样式与网站一致。

如果访问不到，通常是 `github.io` 在当前网络被限制，换个网络或用浏览器的代理再试。

## 特点

- 免登录预约：昵称 / 手机号 任填其一
- 手机号格式校验（11 位）
- 4 大分类筛选：吃 · 喝 · 玩 · 休闲
- 预约码到店核销
- **每张商家卡显示「今日预约 N 单」**：只统计当天收到的预约，**隔天自动归零、不累计**
- 「我的预约」自助查询、取消，每条可单独存**存根图片**
- 预约成功后自动生成**存根图片（PNG）**，一键保存到本机
- 首页可一键「导出全部预约」JSON，交给桌面管理台
- 桌面管理台：确认 / 完成 / 取消 / 删除、筛选搜索、统计营业额
- **一键保存到电脑桌面**（PNG / JSON / CSV），也支持导入 JSON
- **每个商家独立分享**：每张卡片有「分享」按钮，可单独发这个商家的预约链接 / 二维码 / 文案，对方打开或扫码直接进入该商家的预约页
- 浅色主题，响应式，手机端可用

## 今日预约数（隔天归零）

每张商家卡片右上角有一个「N 单 · 今日预约」的角标：

- 只统计**创建时间落在今天**的预约，所以**每天自动从 0 开始，不累计历史**
- 按浏览器**本地时区**判断今天，23:59 提交的算今天，00:00 之后就算新的一天
- 已取消的预约不计入；已确认 / 已完成的仍算「今天收到过」
- 页面一直开着不用刷新，跨过零点 30 秒内会自动归零

## 预约存根（图片）

预约成功后弹窗里会直接画出一张**存根图片**，点「保存存根图片」即可存成本机 PNG：

- 存根是一张真正的**图片**（不是 JSON / 文本文件），含预约码、项目、时间、人数、金额、联系方式、备注、状态
- 文件名形如 `预约存根-A7K2M9-川味老火锅.png`
- Chrome / Edge 会弹出保存对话框，把位置选到 `E:\桌面1` 即可；其他浏览器进下载目录
- 「我的预约」里每条记录也有「存根」按钮，可随时重新保存旧预约的存根图片


## 商家分享

每张商家卡片右下角都有「分享」按钮，点开后是**只属于这一家**的页面链接和二维码：

- **复制链接 / 复制文案**：一键复制，粘给客人即可
- **保存二维码**：把二维码 PNG 存到桌面，可打印放在店里
- **深链直达**：链接形如 `https://lianchuzhong.github.io/cg/?i=hotpot`，对方打开后自动弹出这家店的预约表单，页面只定位到该商家，其它项目不会出现

## 预约通知（GitHub → 邮件 + 电脑弹窗）

客户提交预约后，数据会**上报到私有仓库** `lianchuzhong/cg-orders`（每笔预约 = 一个 issue）：

```
客户提交预约
   │
   ├─► cg-orders 开一个 issue（带 booking 标签）
   │      ├─► GitHub 通知邮件立刻发到商家邮箱
   │      └─► 桌面「预约网站监控」每 5 分钟检查一次
   │             ├─► 弹出 Windows 桌面通知
   │             ├─► 追加一行到 预约记录.csv
   │             └─► 自动给该 issue 打「已处理」并关闭（队列清空，记录不丢）
   │
   └─► 同时照常写入客户浏览器 localStorage（断网也能提交）
```

### 桌面上要准备的东西

| 文件 | 作用 |
| --- | --- |
| `E:\桌面1\预约网站监控\监控.ps1` | 监控脚本本体 |
| `E:\桌面1\预约网站监控\预约记录.csv` | 每条预约一行，Excel 双击不乱码 |
| `E:\桌面1\预约网站监控\监控日志.txt` | 运行日志 |
| `E:\桌面1\预约网站监控\状态.json` | 上次处理到哪一条，避免重复提醒 |

### 手动操作

```powershell
# 立刻检查一次
& "E:\桌面1\预约网站监控\监控.ps1"

# 已注册计划任务「预约网站监控」，每 5 分钟自动运行
Get-ScheduledTask -TaskName '预约网站监控'
Start-ScheduledTask -TaskName '预约网站监控'
```

> ⚠️ 计划任务在**你登录状态下**运行才能弹 Windows 通知；
> 注销后任务仍会跑，但只有日志、没有弹窗。

### 上报失败不影响下单

上报是**异步且永不阻塞**的：即使网络不通、令牌失效，客户的预约照样提交成功，
只是收不到邮件和弹窗。成功弹窗里会显示「已通知商家」或提示未送达。

### ⚠️ 已知风险

`assets/js/store.js` 里保存着一个 GitHub 访问令牌（分片乱序存放，用于在前端直接开 issue）。
**分片只是障眼法，任何人都能还原。**

建议尽快换成**只授权 `cg-orders` 一个仓库、只勾 `Issues: Read and write`** 的细粒度令牌，
换完删掉旧令牌。在此之前，**不要把这个令牌用在其他仓库**，也**不要发给任何人**。

### 预约成功后跳转 tg 站

预约成功后，弹窗底部会出现倒计时，**默认 8 秒后自动跳转**到
`https://lianchuzhong.github.io/tg/`。

- 预约码要「到店出示」，所以不会瞬间闪走，倒计时期间可先看清预约码、存根图。
- 点「**留在此页**」可取消自动跳转；点「**前往 tg 网站 →**」立即跳转。
- 点弹窗右上角关闭 / 按 `Esc` / 点「关闭」同样会取消跳转，不会被强行带走。
- 倒计时秒数在 `assets/js/app.js` 顶部：`var TG_REDIRECT_SEC = 8;`
  想更快/更慢改这一处即可（改 `0` 就是提交后立即跳转）。

> 上报到 GitHub 的请求带了 `keepalive`，所以跳转不会把通知掐断 ——
> 客户被跳走的同时，商家照样收到邮件和电脑弹窗。

## 数据存放（重要）

预约数据**只保存在浏览器** `localStorage` 中，**不会上传到任何 GitHub 仓库或服务器**。

网站（`github.io`）和桌面管理台（`file://`）属于**两个不同的存储空间**，数据不互通。
所以两边用 JSON 搭桥：

1. 在网站「我的预约」点「导出全部预约」→ 得到 JSON 文件
2. 桌面管理台点「导入 JSON」→ 选中该文件，预约数据就进来了
3. 管理台可再导出 CSV / JSON 留档

需要留档时，在管理台点击「保存 JSON 到桌面 / 保存 CSV 到桌面」：

- Chrome / Edge：会弹出保存对话框，把位置选到 `E:\桌面1` 即可
- 其他浏览器：文件进下载目录，可在浏览器设置里把下载目录改为桌面

## 桌面管理台

双击 `E:\桌面1\商家管理台.html` 打开，单文件、离线可用、样式与网站一致。
首次使用留空口令直接进入；如需口令，可在 `localStorage` 键 `cg.settings.v1` 中设置 `{"passcode":"你的口令"}`。

## 增删项目

编辑 `assets/js/data.js` 的 `window.ITEMS`：

```js
{
  id: "hotpot",        // 唯一 ID
  name: "川味老火锅",
  cat: "food",         // food 吃 / drink 喝 / fun 玩 / relax 休闲
  emoji: "🍲",
  price: 128,
  unit: "人均",
  duration: "约 2 小时",
  addr: "人民路 88 号 3 楼",
  desc: "一句话介绍",
  tags: ["包间", "可订位"]
}
```

改完刷新页面即可生效。
